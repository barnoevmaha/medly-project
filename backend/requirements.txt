# Exact pins, frozen from a clean venv on Python 3.13 — the interpreter the
# Dockerfile uses, and one with prebuilt wheels for the whole tree. On a newer
# interpreter a pin may have no wheel yet, and pip falls back to building it
# from source (pydantic-core needs Rust for that). Use 3.13.
#
# To upgrade: in a fresh 3.13 venv, install the direct dependencies below
# without their `==` pins, run `pytest`, then re-freeze
# (`pip freeze --exclude pip --exclude setuptools --exclude wheel`) and copy
# the versions back here. Test tooling lives in requirements-dev.txt.
#
# Two dependencies were deliberately removed:
#   passlib      — imports the stdlib `crypt` module, deleted in Python 3.13.
#                  bcrypt is used directly instead; it is what passlib called.
#   python-jose  — effectively unmaintained and drags in ecdsa + rsa.
#                  PyJWT does the same job and is actively released.

# --- direct dependencies ---

# The [email] extra pulls in email-validator, which pydantic needs for the
# EmailStr field on the registration model. Without it the app raises at import
# time, not at request time — the whole API fails to start.

# Database drivers. Both are unused when MEDLY_DATABASE_URL points at SQLite,

# not a rebuild. PyMySQL rather than mysqlclient because it is pure Python and
# needs no C toolchain in the image.

# Medly AI (MEDLY_ASSISTANT_PROVIDER=gemini) needs no extra package. It calls

# package is a clear runtime message rather than a failed deploy.
